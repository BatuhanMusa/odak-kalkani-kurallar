# Odak Kalkanı – Engel Kuralları

Odak Kalkanı Android uygulamasının Instagram Reels ve YouTube Shorts'u tanımak için kullandığı kural listesi.
Uygulama bu dosyayı günde iki kez okur; Instagram/YouTube güncellenince kurallar buradan düzeltilir.

Değişiklik yaparken `surum` numarasını mutlaka 1 artır.
